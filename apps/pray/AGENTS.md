# 一念 · 3D 祈愿

用户已明确要求上线，每次祈愿收款人民币 1 元。游览免费；仅微信服务端验签确认付款后生成唯一祈愿记录。不能模拟生产支付成功，不向用户承诺考试、学历等现实结果。

应用只拥有 /pray、/pray/*，独立 sunpb-pray Worker 和 D1。不得覆盖自习室、图片模块或其数据库。商户凭据与图片模块共用，不可轮换其密钥。不得重启旧支付测试。

生产更新只能 npm run deploy：测试、构建、完整私有 SQL 备份、恢复验证、迁移、发布、数据保留校验。首次空库也要导出。不得删除原订单、仪式记录、交易编号，不回灌旧数据。商户密钥、.dev.vars、.data/ 均不得提交或展示。

心愿默认私密，文字只存浏览器；服务器保存哈希、分类、订单和交易。用户显式勾选分享或点击公开按钮后，原心愿可匿名保存到 prayer_messages 并公开；撤回只设置 hidden_at，保留原始记录。不得默认公开、自动分享旧心愿或伪造留言。一次付款只对应一个心愿哈希，幂等完成。已付款订单的重试不得重新收款。原账号及其他项目未提交文件不得混入此模块提交。

纪念园位于 /pray/memorial/，当前创建免费，不能自动套用祈愿的 1 元收费。纪念逝者、宠物与其他动物；一张照片与故事保存到同一独立祈愿数据库的 memorials 表，默认私密。持有设备凭据或单条记录管理密钥才可编辑，私密资料禁止通过公开列表、缓存或图片地址泄露。管理凭证只存创建者浏览器，服务端只存哈希；导出文件包含单条纪念的恢复密钥，不得包含设备全局凭据。所有权及创建时间发布时不可变，允许带 revision 乐观锁的显式内容修改和公开范围变更。保留云端全部纪念资料、照片与恢复哈希。

用户关心网站负载：3D 在客户端渲染；静态资源按内容哈希缓存。纪念列表 12 条分页，不返回照片和全文，按需读取详情，不做高频轮询；照片在客户端压缩，服务端只收最大 180 KiB 的 JPEG，最长边 1024；浏览器输出最长边 640。每设备暂限 20 条，创建按 IP/设备限频。不声称承诺任何并发人数或永久无限存储。
