# 一念 · 山间祈愿

独立的 Three.js 3D 寺院与微信支付网站，生产地址 `https://sunpb.com.cn/pray/`。

## 功能

- 真实 3D 寺院、庭院、山门、池塘、人物和祈愿殿；自动寻路、WASD/方向键、点击地面和触屏摇杆。
- 考试顺利、升学上岸、学业有成、平安顺遂四类心愿，支持自定义文字。
- 免费游览；每次祈愿服务固定人民币 100 分，包含一次祈愿动画和一张可下载的祈愿笺。
- 微信 Native 扫码收款，验签、API v3 解密、金额/商户/订单校验、主动查单、关闭未支付订单。
- 服务器以交易编号与订单唯一约束防重；一次支付只生成一个心愿哈希对应的祈愿记录。重试与查看已有祈愿笺不重复收费。
- 祈愿墙免费浏览，按时间分页。完成祈愿后自愿匿名公开，默认私密；可以撤回公开留言。
- 订单凭据、私密心愿文字和草稿保存在当前浏览器；服务器保存心愿摘要、分类、订单与支付必需信息，明确公开的文字另存留言表。清除浏览器数据会丢失本机访问凭据，付款页面提供订单号留存。
- 无需图片模型、R2 或 Queue；不改动图片合成与自习室应用。

这是虚拟数字体验，不是真实寺院服务，不保证现实愿望实现。当前接入 Native 扫码，不包含微信内 JSAPI/H5 拉起支付；同一手机直接拉起支付需另行开通对应产品。

## 开发与发布

```sh
npm ci
npm run dev
npm test
npm run build
```

开发页 `/pray/`，API 代理到本地 8799 端口。需要完整本地 API 时，先运行 `wrangler d1 migrations apply sunpb-pray --local`，再运行 `wrangler dev --port 8799`。没有商户密钥时支付按钮禁用。

生产只使用 `npm run deploy`；需要首次导入商户配置时使用 `npm run deploy -- --secrets .data/deploy-secrets.json`。脚本自动测试、构建、导出完整线上 D1、临时 SQLite 恢复验证、迁移、发布、再导出核验历史订单和祈愿。私有备份存于 `.data/backups/`，不回灌数据库，不绕过备份脚本。商户密钥与已有图片模块共用，不可擅自轮换。

资源：Worker `sunpb-pray`，独立 D1 `sunpb-pray`；仅挂载 `/pray` 和 `/pray/*`。微信通知地址 `https://sunpb.com.cn/pray/api/payments/wechat/notify`。

浏览器检查覆盖电脑、手机入殿、付费流程（隔离构造响应）、祈愿笺下载和刷新后的记录恢复。构造支付响应只存在于离线检查，不提供线上模拟支付开关，也不代表真实到账。
